# 部署说明 · 微信云开发

这份文档把「本地演示」变成「真正联网、数据存在云上」的完整过程走一遍。全程只需要微信开发者工具 + 一个云开发环境，不需要买服务器、不需要备案域名。

```
浏览器（web/ 静态页面）
      │  POST application/json
      ▼
云函数 api   ← HTTP 访问服务（一个公网地址）
      │
      ├─→ 云数据库（users / products / carts / orders / addresses）
      └─→ 云存储（商品图片）
```

---

## 1. 准备工作

| 项 | 说明 |
|---|---|
| 微信开发者工具 | [下载稳定版](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，需要一个已注册的小程序账号 |
| 云开发环境 | 开发者工具里点「云开发」→ 开通 → 新建环境（按量计费，学生项目基本在免费额度内） |
| 环境 ID | 开通后在「设置 → 环境」里能看到，形如 `campus-market-8g9x0xyz` |

> 没有小程序账号也能用：腾讯云 CloudBase 控制台单独开一个环境，后面步骤完全一样。

---

## 2. 建 5 个数据库集合

云开发控制台 → **数据库** → 新建集合，依次建：

```
users      products    carts      orders      addresses
```

每个集合建好后，点「权限设置」→ **自定义安全规则**，内容改成：

```json
{
  "read": false,
  "write": false
}
```

**为什么要这样**：所有读写都由云函数完成，云函数用的是管理员权限，不受这条规则限制；而浏览器端的任何直连都会被拒绝。这样即使有人拿到前端代码，也改不了数据库里的任何一个字段。

**建索引**（数据上千条后再加也行，但顺序别错）：

| 集合 | 字段 | 类型 |
|---|---|---|
| products | status + createdAt（复合索引，createdAt 降序） | 普通 |
| products | sellerId | 普通 |
| carts | userId | 普通 |
| orders | buyerId | 普通 |
| orders | sellerId | 普通 |
| users | phone | **唯一** |

---

## 3. 部署云函数

1. 在微信开发者工具里新建/打开一个项目，把本仓库的 `cloudfunctions/api` 整个目录放进去。
2. 确认项目根目录的 `project.config.json` 里 `cloudfunctionRoot` 指向 `cloudfunctions/`（工具里勾选「使用云开发」时会自动生成）。
3. 右键 `api` 目录 → **上传并部署：云端安装依赖**。
4. 到云开发控制台 → 云函数 → api → 配置：
   - 运行环境：**Node.js 16** 或更高
   - 超时时间：**20 秒**（发布商品要处理最多 5 张图）
   - 内存：**256 MB** 足够

`package.json` 里同时列了 `@cloudbase/node-sdk` 和 `wx-server-sdk`，云函数会优先用前者，取不到再回退后者，所以微信云开发和腾讯云 CloudBase 两种环境都能跑。

---

## 4. 配置环境变量

云开发控制台 → 云函数 → api → **配置 → 环境变量**，加两项：

| 变量名 | 值 | 作用 |
|---|---|---|
| `TOKEN_SECRET` | 随便一串长随机字符串，**务必改掉** | 登录令牌的签名密钥。不改的话，别人可以自己伪造登录态 |
| `ADMIN_CODE` | 自定义，例如 `XMU-2026-ADMIN` | 注册时填这个码就成了管理员。留空则默认 `CAMPUS-ADMIN` |

改完点保存，云函数会自动重启。

---

## 5. 打开 HTTP 访问服务

云开发控制台 → 环境 → **HTTP 访问服务** → 新增：

- 路径：`/api`
- 方法：`POST`（同时勾上 `OPTIONS`，个别浏览器会发预检）
- 绑定云函数：`api`
- 响应方式：**集成响应**（关键，不选的话浏览器拿到的是包了一层的格式）

保存后会得到一个地址，形如：

```
https://campus-market-8g9x0xyz.service.tcloudbase.com/api
```

> 这个默认域名是给调试用的，长期对外请绑定自定义域名。

---

## 6. 前端接入云端

打开 `web/js/config.js`，把地址粘进去：

```js
export const CLOUD_ENDPOINT = 'https://campus-market-8g9x0xyz.service.tcloudbase.com/api'
```

保存、刷新页面。此时：

- 「我的」页面底部会显示 **已连接云开发环境**
- 登录页的「本地演示账号」提示会自动消失
- 注册的账号、发布的商品会真正存到云数据库

**留空** 则继续跑本地演示模式（数据在浏览器 localStorage 里），适合先看效果。

## 7. 把页面也放到云上（可选）

本地双击 `start.cmd` 只是本机预览，别人访问不到。要给别人用，把页面传到云开发 → **静态网站托管**。

**关键：要传 `web/` 里面的东西，不是 `web` 这个文件夹本身。** 传完根目录下必须直接是 `index.html`、`css/`、`js/`；如果变成了 `/web/index.html`，打开首页就是 404。

三种传法：

- **一键脚本**（已经配好环境和路径，双击即可）：

```
deploy.cmd
```

- **命令行**（等价，CI 里也用这个）：

```bash
tcb hosting deploy ./web -e 你的环境ID
```

- **控制台**：静态网站托管 → 文件管理 → 上传文件，先双击进入 `web` 目录再全选上传

本项目当前已部署在：

```
https://cloud1-d5genhgf2b9f44de6-1538086108.tcloudbaseapp.com/
```

改了前端代码后，重新 `deploy.cmd` 一次就会更新；用 `npm run probe:site` 检查，根路径和 `/index.html` 都应该是 200。

常见坑：

- 服务刚开通时状态是「初始化中」，这期间上传会被拒绝，等几分钟重传
- 控制台「基础配置」里的**索引文档**要设成 `index.html`
- 静态托管默认域名形如 `https://<环境ID>-<数字>.tcloudbaseapp.com`，不是 `*.webapps.tcloudbase.com`（那个是「Web 应用」产品的地址，两个不是一回事）
- CDN 有缓存，刚传完看到旧页面时用无痕窗口或等几分钟

不用改任何代码：云函数已经返回 `Access-Control-Allow-Origin: *`，换域名不受影响。

## 8. 注册第一个管理员

打开登录页，切到「注册」，手机号、密码、昵称、学校、学号正常填，最下面的**管理员注册码**填你在第 4 步设置的 `ADMIN_CODE`。

**没设置过环境变量的话，直接填 `CAMPUS-ADMIN`**（这是默认值）。

注册完成后，顶栏点头像 → 「管理员后台」就能进了。

> 注册时如果没有填管理员码，普通账号也可以在数据库控制台手动改：`users` 集合里找到自己那条记录，把 `role` 改成 `admin`，然后**退出登录并重新登录**——角色是写进登录令牌的，不重登不生效。

## 9. 导入演示商品（可选）

新库里一件商品都没有，首页是空的。想立刻看到效果，可以导入 6 件演示商品：

1. 用管理员账号登录网页。
2. 浏览器按 F12 → Console，执行 `localStorage.getItem('cm_token')`，复制输出的那串字符（含引号，去掉引号）。
3. 云开发控制台 → 云函数 → api → **云端测试**，测试参数填：

```json
{ "action": "admin.seedDemo", "token": "刚才复制的令牌" }
```

4. 返回 `{"ok":true,"data":{"count":6}}` 后刷新首页即可。

## 11. 安全设计说明

- **密码**：`scrypt` 加随机盐，数据库里只有哈希，没有明文。
- **登录态**：HMAC-SHA256 签名的令牌，30 天有效；密钥在 `TOKEN_SECRET` 环境变量里，服务端不存 session。
- **数据库**：安全规则设成 `read:false / write:false`，浏览器无法直连，只能经过云函数。
- **越权**：改资料、下架、看订单等操作都会校验「这条数据是不是你的」；管理员接口额外校验 `role === 'admin'`。
- **下单竞态**：下单前逐个校验商品状态必须是 `on`，下单后立刻改成 `reserved`，同一件东西不会被两个人同时买走。
- **输入校验**：手机号、学号、价格区间、标题长度、图片数量都在服务端再校验一遍，前端校验只是体验优化。

## 12. 常见问题

**页面提示「连不上服务器，请检查网络，或确认云函数地址是否正确」**
逐一排查：`CLOUD_ENDPOINT` 是不是以 `/api` 结尾、是不是 `https://`、HTTP 访问服务路径是否真的叫 `/api`。

**接口返回「服务开小差了」**
看云开发控制台 → 云函数 → 日志。最常见的是 `collection not exists`（第 2 步集合没建全）或 `permission denied`（集合权限没关掉）。

**图片上传失败**
确认环境开了云存储；单张图限 3MB（前端已压缩到 900px 以内，正常不会超）。

**商品图片变成裂图（控制台报 `CDN_SIGNATURE_EXPIRED`）**
云存储返回的是**带签名的临时链接，只活十几分钟**。`cloudfunctions/api/index.js` 里的 `URL_CACHE_TTL` 就是这些链接的缓存时长，现在是 2 分钟——**不要往大调**。之前设成 25 分钟时，云函数多实例各缓存各的链接，命中旧实例的图片就会 403，表现为“图片时好时坏、越老的商品越容易裂”。

**首页空空的**
新库没有在售商品。走一遍「发布 → 管理员审核通过」，或按第 9 步导入演示数据。

**改了代码没生效**
前端记得强制刷新（Ctrl+F5）；云函数改完要重新部署（`tcb fn deploy api --dir cloudfunctions/api --force` 或开发者工具里上传）。

**商品接口偶尔超时**
云函数超时默认只有 3 秒，发布带图、批量导入时容易不够。控制台把超时改成 20 秒更稳。

**云函数里中文变问号**
文件必须存成 UTF-8。本仓库的文件已经是 UTF-8，用编辑器另存时注意别选 GBK。

**费用**
云开发按量计费，学生做课程项目一般跑在免费额度里。真要在学校推广，记得在控制台设个资源用量告警。
